---
title: 비용 및 예산
summary: 예산 한도, 비용 추적, 자동 일시 중지 적용
---

Paperclip은 모든 에이전트가 사용하는 모든 토큰을 추적하고 비용이 통제 불능 상태가 되는 것을 방지하기 위해 예산 한도를 적용합니다.

## 비용 추적 방식

각 에이전트 하트비트는 다음 정보를 포함한 비용 이벤트를 보고합니다:

- **공급자** — 어떤 LLM 공급자 (Anthropic, OpenAI 등)
- **모델** — 어떤 모델이 사용되었는지
- **입력 토큰** — 모델에 전송된 토큰 수
- **출력 토큰** — 모델이 생성한 토큰 수
- **센트 단위 비용** — 해당 호출의 달러 비용

이 데이터는 에이전트별로 월 단위(UTC 달력 기준)로 집계됩니다.

## 예산 설정

### 회사 예산

회사의 전체 월간 예산을 설정합니다:

```
PATCH /api/companies/{companyId}
{ "budgetMonthlyCents": 100000 }
```

### 에이전트별 예산

에이전트 설정 페이지 또는 API에서 개별 에이전트 예산을 설정합니다:

```
PATCH /api/agents/{agentId}
{ "budgetMonthlyCents": 5000 }
```

## 예산 적용

Paperclip은 예산을 자동으로 적용합니다:

| 임계값 | 조치 |
|-----------|--------|
| 80% | 소프트 알림 — 에이전트가 중요 작업에만 집중하도록 경고됩니다 |
| 100% | 하드 중지 — 에이전트가 자동으로 일시 중지되며 더 이상 하트비트가 실행되지 않습니다 |

자동 일시 중지된 에이전트는 예산을 늘리거나 다음 달력 월까지 기다리면 재개할 수 있습니다.

## 비용 확인

### 대시보드

대시보드에서 회사 및 각 에이전트의 현재 월 지출과 예산을 비교하여 표시합니다.

### 비용 분석 API

```
GET /api/companies/{companyId}/costs/summary     # 회사 전체 합계
GET /api/companies/{companyId}/costs/by-agent     # 에이전트별 분석
GET /api/companies/{companyId}/costs/by-project   # 프로젝트별 분석
```

## 모범 사례

- 처음에는 보수적인 예산을 설정하고 결과를 보면서 늘립니다
- 예상치 못한 비용 급등을 발견하기 위해 대시보드를 정기적으로 모니터링합니다
- 에이전트별 예산을 사용하여 단일 에이전트로 인한 노출을 제한합니다
- 중요한 에이전트(CEO, CTO)는 개별 기여자보다 높은 예산이 필요할 수 있습니다
